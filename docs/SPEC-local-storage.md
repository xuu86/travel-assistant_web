# SPEC-local-storage：按身份保存 Web 行程

> 版本：v0.1｜状态：待审阅｜对应已批准 Capability Map 的 `local-storage` 模块

## 1. 元数据

- **关联决策：** D-009、D-024、D-035
- **依赖模块：** `auth`、`itinerary`
- **范围：** 当前浏览器本地保存；不提供云端同步或跨设备备份。

## 2. 目标与范围

旅行工作区中的用户操作应在刷新、关闭页面、登出后仍能恢复。行程草稿和后续可选凭证通过 IndexedDB 持久化，并以 `auth` 提供的稳定主体 ID 分区：游客与五个测试账号各自独立。切换身份只切换可见分区，不自动合并或删除其他分区。

首版提供当前行程自动保存、重新打开恢复、按身份列出/读取/删除、数据版本迁移和保存失败提示。不承诺浏览器清理数据后的恢复，不将本地保存误称为云备份。游客数据迁移到账号、跨设备同步和服务端备份不在范围内。

## 3. 数据契约

- 数据库名：应用专用 IndexedDB；对象至少包含 `owner_id`、`record_id`、`schema_version`、`updated_at`、有效行程快照。
- 所有读取、写入、列举、删除和后续导出均必须按当前 `owner_id` 限定；不得接受 UI 提交的任意 owner 作为授权依据。
- 游客使用应用生成并持久化的随机匿名主体 ID；不采集硬件指纹。清理站点数据可能使该游客身份无法恢复。
- 保存只包含应用确认的行程事实、手工编辑条件与业务状态；不保存密码、会话凭据、未确认模型候选、供应商密钥、日志或无关原始文件。
- 在身份切换瞬间，旧身份的异步保存必须完成或被取消；任何迟到写入仍绑定写入时捕获的 owner ID，不能落入新身份分区。
- 使用 `schema_version` 进行可重复、可测试的本地迁移；未知或损坏版本应保留原记录并报告不可读取，不能静默清空。

## 4. 生命周期与状态

| 状态 | 行为 |
|---|---|
| 正在保存 | 对当前 owner 的快照原子写入；允许新编辑排队为较新版本 |
| 已保存 | 刷新、重启或登出后可从同一 owner 分区恢复 |
| 保存失败／空间不足 | 显示可见错误和重试入口；保留内存草稿，不假报成功 |
| 切换身份 | 隐藏旧身份界面数据，加载新身份分区；不得展示其他账号的缓存内容 |
| 删除行程 | 仅删除当前 owner 指定的行程及其关联本地凭证；操作需用户主动触发 |

空分区返回空列表。不存在记录返回未找到，不创建空白数据冒充已保存行程。

## 5. 项目结构与实现约束

- `frontend/src/features/local-storage/`：IndexedDB schema、repository、迁移和测试；现有 `itinerary` 状态通过明确接口保存/恢复。
- 类型继续使用 TypeScript；浏览器数据库访问通过结构化 IndexedDB API，不在 localStorage 放整份行程。
- 不增加 ORM 或新后端存储；实现中使用原生 IndexedDB 或已有依赖。若选择新增依赖须先审批。
- 凭证存储的加密、文件体积上限和清理策略在凭证模块实现前另行规格化；当前不得把任意上传原件加入行程快照。

## 6. 测试策略

- Repository 单测：增删改查、owner 隔离、空/缺失/损坏数据、schema 迁移、事务失败。
- 集成测试：编辑后保存、刷新恢复、登出再登录恢复、游客与账号互不可见、账号 A 到 B 切换无闪现/串写、保存失败时草稿仍留在内存。
- 浏览器 E2E：完成一项行程编辑并刷新后恢复；登出再登录同一账号恢复；另一账号无法读取该行程；主动删除只影响当前账号。
- 命令：`npm run test:unit`、`npm run test:e2e`、`npm run typecheck`、`npm run lint`、`npm run build`。

## 7. 边界与验收

- **Always：** IndexedDB 按稳定 owner 分区；退出保留数据；写入失败明确提示；版本迁移可回归；不静默合并主体。
- **Ask first：** 云端同步、数据迁移、浏览器间共享、备份/恢复服务、持久化保留期限、凭证本地加密策略或新增依赖。
- **Never：** 把账号密码或会话令牌写入行程；用单一共享 key 覆盖游客和账号数据；退出即删除行程；登录即静默上传游客数据；保存失败仍显示“已保存”。

验收条件：各身份的行程在刷新、重启和退出后可恢复；游客及不同账号之间完全隔离；身份切换期间不存在旧界面闪现或旧写入落入新分区；保存失败不会丢弃当前内存草稿且 UI 不谎报成功；用户删除仅影响其选择的当前身份数据。

## 8. 未决问题

- 游客身份的生命周期：当前按本浏览器匿名 ID 保留，清理站点数据后不可恢复；如需显式“重置游客”入口，在计划中确定。
- 当前工作区含多个查询条件和草稿状态。计划阶段需定义最小持久化快照及恢复后的查询刷新语义，避免把瞬时加载/错误状态当作事实保存。
