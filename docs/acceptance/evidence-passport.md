# 信息护照验收

## 已接入数据

- 天气：每个逐日预报卡片可展开来源护照；显示来源、取数时间、来源有效期、请求日期范围及该日覆盖状态。
- 班次：每个航班／铁路班次可展开其来源护照；显示来源、取数时间、来源有效期与服务返回的覆盖范围。交通页面仍只展示班次信息，不添加价格或市内路线查询。
- 地点：每个 POI 结果按 `source_id` 关联 SourceRef，显示来源和来源状态。
- 预算：预算上限、预留金、费用明细分别显示用户提供来源；新输入记录录入时间，已确认订单金额只记录“用户核对的车票订单金额”，不保留原文件名、原件或未确认候选。
- 行程：每项手工安排显示用户录入来源与录入时间；旧快照缺少来源时间时明确显示“未记录”。助手快捷填入的内容标记为状态未知，直到用户编辑确认。

## 规则与限制

- 复用 Foundation `SourceRef`、`EvidenceState` 与 `Coverage`；没有来源有效期或覆盖证据时显示“来源未提供”，不推断仍有效或全范围覆盖。
- 用户手工录入显示 `user_provided`，不伪装为平台核实数据；订单文件解析成功也不会自动视为已付款，仍要求用户核对后才进入预算。
- 详情使用原生 `<details>`，键盘可操作；来源链接只允许 HTTP(S)，新窗口链接带 `rel="noreferrer"`。
- IndexedDB 中现有快照按可选证据字段兼容读取，不清除旧预算或行程数据。
- 当前前端没有路线规划查询界面；按交通展示范围，不为未展示的路线生成虚构的证据入口。

## 验证

- 前端完整 Vitest：21 files / 123 tests passed。
- TypeScript 应用与 E2E 检查通过；ESLint 通过；Vite 生产构建通过。
- 本机桌面浏览器与窄屏浏览器确认预算来源面板可展开且文本不溢出；天气、POI、班次来源入口由组件测试覆盖。
- 真实供应商响应的覆盖和有效期依旧以各自返回字段为准；UI 接入不替代供应商能力验收。
