# itinerary-checkup 任务清单

> 版本：v0.1｜状态：已实施、验收并同步 GitHub/服务器｜依据：[SPEC-itinerary-checkup](../../docs/SPEC-itinerary-checkup.md)、[实施计划](plan.md)。L2 已完成验收并发布后才开始本模块编码。

## 固定规则

- 只做单城市本地只读分析；不自动移动、删除、解锁、写入行程，不接路线/地图/营业时间/预约 provider。
- 所有新增行程输入可空、默认 null、标 `user_provided`；旧 IndexedDB snapshot 兼容；不将缺省解读为 0。
- 天气只接受已覆盖行程日的当前非-demo天气数据；预算复用现有预算金额/完整性语义；L2 权重来自已验收 ledger。
- 维度充分性必须显式验证；任一维不足不显示综合分；建议不超过三条且有来源字段和稳定排序。
- 每个任务先加失败测试再实现，逐项执行；L2 发布验收前不得开始本模块编码。

## 任务（按依赖顺序）

### IC-01 — 为行程安排增加可选体检字段

- [x] **验收：** 新增停留分钟、下一段通行分钟、室内/户外/未知、步行公里、台阶数、换乘数输入及严格校验；默认未知，不允许负值/隐式补零；旧快照兼容；锁定安排不可被体检编辑流程绕开；证据护照标用户提供。
- **验证：** ItineraryPanel 单测覆盖新增/编辑/取消/锁定、空值、合法边界、旧 snapshot restore、owner 切换和本地保存。
- **文件：** ItineraryPanel、itinerary-panel.css、ItineraryPanel.test.tsx、字段模型及 tests（分批，每项 ≤5 个文件）。
- **依赖：** L2 发布完成；获批计划。

### IC-02 — 实现时间与预算维度计算

- [x] **验收：** 时间使用每日首项开始至末项结束跨度，活动时长=停留+段间交通，缓冲取 max(0,跨度-活动时长)；必要输入缺失/跨度≤0 则 insufficient；时间得分为每日最差值，30% 缓冲率为 100 分。预算仅在上限>0、全部必要金额已知且 complete 时计算，支出=已付+待付+用户预留，余量率 30% 得满分并 clamp 0..100；不将未知金额当 0。
- **验证：** 纯函数单测覆盖 null/0、零预算、超支、跨日时间段、重叠时段、边界分、最差日策略、输入确定性。
- **文件：** `checkup.ts`、`checkup.test.ts`（2 个）。
- **依赖：** IC-01。

### IC-03 — 实现体力与天气维度计算

- [x] **验收：** 体力负荷率为 `max(walk_km/10, stair_steps/100, transfers/8, continuous_outdoor_minutes/480)`，舒适分 clamp(1-load)*100；维度任一必要指标缺失即不足。天气雨险分钟=户外分钟×降水概率；60 分钟为满风险分；雷暴95–99、冻雨66–67、强雪75/86 或 >35℃/<-5℃风险分100；舒适分=100-risk；缺 coverage/字段/室内外/时长即不足。仅读取非-demo有效天气。
- **验证：** 纯函数测试覆盖所有阈值边缘、天气代码、混合室内外活动、coverage 不完整、demo/过期/邻日不补齐。
- **文件：** 计算器与测试（最多 5 个）。
- **依赖：** IC-01、IC-02。

### IC-04 — 实现未知项维度、综合分和建议排序

- [x] **验收：** 高/中/低未核实项分别扣 20/10/5 分，最低 0；读取 coverage 不完整时维度 insufficient。五维都有分才取算术平均为综合分；否则隐藏综合分。建议依据明确异常、影响等级、旅行日、稳定 ID 排序，最多 3 条；无自动 mutation，锁定行程只提供只读链接。
- **验证：** 确定性单测覆盖重复到期项不重复扣分、coverage gap、综合分完整性、建议排序及限制数目。
- **文件：** 计算器与 tests（最多 5 个）。
- **依赖：** IC-02、IC-03、L2 ledger API。

### IC-05 — 集成行程体检视图与刷新逻辑

- [x] **验收：** 行程页可打开体检，显示每维分数/“数据不足”、口径、覆盖度、异常与最多三条建议；来源字段可回到原安排；输入变化后即时重算，不展示陈旧分数；图形若存在有等价文本；视觉遵循当前风格和响应式规范。
- **验证：** 组件单测覆盖空行程、部分/完整输入、预算/天气/ledger 变化、键盘和屏幕阅读器标记；375px 不溢出。
- **文件：** ItineraryPanel、checkup panel、样式、组件测试（≤5 个/批）。
- **依赖：** IC-01 至 IC-04。

### IC-06 — 全回归、验收留证并逐模块发布
