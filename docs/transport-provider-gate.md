# 交通真实票价 Provider Gate

> 核查日期：2026-10-29（北京时间）
> 范围：TLP-00 官方资料审阅；**TLP-00 阶段未调用航班/铁路班次或票价查询接口**，未读取/保存真实查询结果。
> 结论：同程航班、12306 铁路均为 **BLOCKED（不得实现为可启用 live provider，不得发真实查询请求）**。本记录只覆盖公开资料审阅，不构成法律意见或供应商授权。

## 同程：公开材料

1. [同程旅行法律声明](https://www.ly.com/public/law.html)，访问日期 2026-10-29：页面说明资料下载仅供个人学习研究使用，不得用于商业用途；未经网站或版权所有者明确书面同意，不得分发、修改、散布、再使用、再传递或用于公众商业用途。该声明至少无法证明本项目可抓取并再展示机票数据；本项目用途尚需项目负责人/权利方确认。
2. [同程旅行用户协议与隐私条款目录](https://www.ly.com/public/Lawprotocols)，访问日期 2026-10-29：页面列有“同程旅行服务协议”“软件许可使用协议”“机票预订协议”。本次可访问目录中“机票预订协议”只有目录标题，未取得可审阅的协议正文或任何第三方自动化访问许可。因此不把目录存在解释为授权。
3. [同程国内机票入口](https://www.ly.com/flights/home)，访问日期 2026-10-29：公开服务页面存在；它是用户网页入口，不是经核实的第三方 API 文档。未审阅或调用任何航班查询 endpoint。
4. [上游 fly-flight 仓库](https://github.com/baizhexue/fly-flight)：仓库未声明可见开源许可证。项目不得复制其实现；其描述的公开页面来源也不替代同程授权。

**字段/运行语义：**官方可审阅材料未确认页面抓取频率、限流/封禁规则、允许缓存时间、可再展示范围、实际价格单位和价格对应单人/团队、税费包含项、航班时间区、数据更新时间或五城机场映射。现阶段不得将抓取页面中的数字映射为 CNY 整数分或 `live` 证据。

## 12306：公开材料

1. [12306 互联网购票常见问题](https://kyfw.12306.cn/otn/gonggao/onlineBooking.html)，访问日期 2026-10-29：官方说明 12306 网站提供旅客列车时刻表、余票、票价等客运信息查询；同页建议使用官方网页/客户端购票，并提示不要使用非官方网站或手机 App 购票，以避免个人身份信息泄露。该资料描述面向用户的官方服务，不是第三方程序化 API 文档，也未授权本项目调用内部 endpoint。
2. [铁路旅客运输规程](https://kyfw.12306.cn/otn/gonggao/saleTicketMeans.html?linktypeid=means2)，访问日期 2026-10-29：官方规程说明车票主要信息包括票价、车次、乘车日期和时间；第八条说明票价为旅客购票时的执行票价。儿童票规则需结合符合优惠条件的未成年人资格判断，当前查询只传成人 purpose code 的候选接口不能证明儿童报价。
3. [12306 官方首页/服务导航](https://kyfw.12306.cn/otn/index/init)，访问日期 2026-10-29：提供“公布票价”“时刻表”等官方信息查询入口；页面同时声明铁路未授权其他网站或 App 开展类似服务内容。该提醒的适用范围未明确细分“查询”与“购票”，故本项目将自动采集/再展示资格保持未决并阻止接入，而不擅自扩大或缩小其范围。

**字段/运行语义：**公开材料未提供 `queryG` 或 `queryAllPublicPrice` 的稳定、获授权第三方 API 契约；金额编码单位/精度、字段索引、余票文本含义、查询频率/限流、日期覆盖和响应稳定性均未获官方文档确认。公开运输规程也不证明任一非官方接口响应可作为实时、可复用报价。

## 地点覆盖与映射

城市级输入无法唯一识别机场/车站：上海有多个民航机场和铁路站，杭州、苏州、无锡、嘉兴也存在多个机场/车站或跨城可达站点。当前项目没有获验证的供应商稳定代码目录及用户 disambiguation flow。不得从城市名静默映射机场/车站、将浏览器坐标 geocode 成机场/车站，或使用城市中心替代。

TLP-00 未建立五城映射表，因为其只能来自已获准、稳定且可核验的来源数据；没有把仓库样例、历史别名或未经批准的页面提取值提升为 verified。

## 测试/请求边界

- 本 Gate 阶段只审阅官方法律/帮助/规程网页和仓库许可证元数据。
- **更正历史操作：**在此前分析 `fly-flight` 上游实现时，曾两次 GET 同程公开航班结果页 `https://www.ly.com/flights/itinerary/oneway/BJS-SHA?date=2026-11-10`，即北京（BJS）至上海（SHA）、2026-11-10。请求没有携带乘客信息；响应只用于检查页面是否含 SSR 数据结构，没有将报价或班次写入项目，也未调用独立 JSON 票价 API。该访问发生在 TLP-00 法律资料核查之前，按项目门禁不视为授权的受控 live smoke，且不构成真实数据验收证据。
- 未请求 12306 班次/票价查询端点；TLP-00 期间未请求同程航班结果页，也未提交新地点、日期或乘客信息。
- 没有真实票价响应，因此没有测试币种、票价单位、余票/库存或数据新鲜度。
- 公开资料无法证明授权时，后续任务 TLP-01 至 TLP-05 中相应 live provider 保持 deferred；只能在用户另行批准且 Gate 证据充分后重开。

## 重新开启 Gate 所需证据

1. 同程对本项目用途的书面自动化访问和结果展示授权，或明确适用的、官方文档化的开放 API/合作接口条款；并确认署名、频率、缓存及价格字段语义。
2. 12306 对目标第三方程序化查询接口的官方授权/开放 API 条款，或项目负责人认可且有书面依据的授权解释；并确认请求频率、票价单位/精度、余票字段和儿童票语义。
3. 取得来源允许使用的稳定城市/机场/车站目录和唯一性规则，定义歧义地点的用户选择流程。
4. 对每个来源独立批准限量 live smoke 的地点、日期、次数、环境、证据保存和脱敏方式。用户批准本计划或 mock 实现不等于此项授权。
