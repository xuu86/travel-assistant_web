# SPEC — FlyAI 火车票查询 Provider 接入（MVP）

> 状态：v0.2，2026-10-31 用户明确批准改为后端封装官方 CLI，实现网页铁路查询；缺价显示“票价未返回”。此前单次真实 Key 查询通过。以下契约取代 v0.1 对生产 CLI 的排除，实施及验收见[记录](acceptance/transport.md)。
> 证据与缺口：[官方契约核查记录](flyai-train-contract-review.md)。

## 目标

在现有交通模块中新增独立的 FlyAI 火车查询 Provider，评估并在可用配置下查询列车班次及供应商实际返回的票价。API Key 仅由后端保管。未配置或无权限时明确返回 `unconfigured` / `policy_unavailable`，不回退到 mock 或其他抓取来源。

## 范围

- 使用飞猪 AI 开放平台官方 FlyAI CLI/Skill 所支持的结构化 `search-train` 能力，不在项目运行时全局安装或直接执行第三方 Skill。
- 验证官方支持的服务端调用契约、正式账户权限、价格字段、席别语义、限流/缓存/展示规则和授权用途。
- 以固定 `@fly-ai/flyai-cli@1.0.16` 为明确依赖，在后端实现独立 `FlyAITrainFareProvider`，适配现有 FareProvider 契约；不直接调用提取出的内部 HTTP 协议。
- 对车次、发到站/时间、席别、CNY 票价、余票分别映射；缺字段留空并记录 `missing_fields`，不估算票价或余票。
- 前端在用户明确选择铁路后展示来源、查询时间、席别、必要的平台纯文本提示，以及供应商返回且通过官方 HTTPS 域名校验的外部详情链接；不自动访问链接，不提供应用内订单或支付。
- 加入 mock/合成响应测试、默认关闭配置测试、脱敏与错误处理测试；无 Key 时不发网络请求。

## 非目标

- 不使用 RailGo 或 12306 内部接口作为此 Provider 的隐式 fallback。
- 不实现购票、下单、支付、锁价、锁位或自动重试到其他服务。
- 不承诺 CLI 输出长期稳定；固定版本并严格检查结构，变化时返回 unavailable；不自行实现包内 HTTP 协议。
- 不把单次本地查询解释为公网部署、全部账户权限、配额或确定票价验收。用户已批准真实核验及 CLI 后端方案；本地 API 链路已完成另一次限定查询，见验收记录。

## 已知假设与边界

- FlyAI 官方文档列出 `search-train` 结构化火车票搜索能力；快速开始要求从控制台获取 `FLYAI_API_KEY`。需核实官方 API/CLI 的机器调用方式与授权。
- 当前代码库使用通用铁路 FareQuery/FareOffer 契约，具体席别、币种、票价基准需从真实官方文档确认后再定映射；不可根据自然语言输出猜字段。
- 仓库默认配置关闭；本地已按用户批准显式启用。公网部署的账户/用途、配额及缓存规则另行落实。

## 验收标准

### v0.2 已批准的 CLI 适配边界

- 铁路配置独立于航班；默认不启用，显式 provider、非空服务端 SecretStr Key、可用 Node 与固定版本 CLI 才能调用。支持现有 `FLYAI_API_KEY`，不得回退到内置试用凭据。
- 无 shell 拼接；请求地点和日期通过 stdin 传入受控 Node 启动器。Key 仅子进程环境传递，不继承 debug、代理、TLS 绕过及 Node 注入配置。
- 启动器仅允许官方 HTTPS MCP 目标、一次 POST、匹配的 Authorization、TLS 校验、禁止 redirect；45 秒请求及 50 秒父进程超时、1 MiB 响应/输出限制、最多 2 个并发进程、无重试。CLI 未部署返回 `unconfigured`，进程/协议异常返回 `unavailable`，HTTP 401/403 和 429 分别映射权限及限流。
- 上游业务成功必须同时符合 HTTP 200、CLI exit 0、业务 `status=0`、数组结果；未知业务错误不推断其含义。仅接受铁路分段和请求日期，保留换乘顺序；国内铁路无偏移时间按 Asia/Shanghai 解释，格式错误时间保留未知。
- 席别按分段保留。CLI 不支持人数参数，不声称结果已按成人/儿童人数报价或筛选余票，计价人数基准与数量保留未知。
- 当前版本不把 `adultPrice` 格式化文本解析为确定金额；缺失或无法确认语义的金额为 null，铁路卡片显示“票价未返回”。不构造币种/税费/整单价格、余票或价格估算。
- 供应商 `jumpUrl` 只允许已列明的官方 HTTPS 域名，禁止凭据、异常端口及控制字符；作为外部详情链接返回。平台提示按纯文本展示，任何 HTML 不执行。品牌与来源保留，响应含 Key 时整体拒绝。
- 验证包括配置、映射、进程边界、HTTP/业务错误、默认无上游、航班/铁路隔离、类型生成、前端缺价/席别/链接及桌面/移动 E2E。真实链路使用已有授权进行一次本地 API smoke，仅落盘脱敏摘要。

1. 固定官方 CLI 版本和完整性，有官方命令参考及真实样本字段核验；直接 HTTP/SDK 契约缺口不再阻止 CLI 方案实施，未确认字段继续保留未知。
2. 有本项目账户/Key 的功能权限与使用用途核准；不在仓库、日志或前端暴露 Key。
3. 未完整配置时服务状态为 `unconfigured` 且没有供应商网络请求；权限错误映射为明确状态，不使用 fallback。
4. 合成数据测试证明班次、时间、席别与票价字段不混淆；金额精度、币种和票价基准经过校验；未知字段保持 null。
5. 真实查询遵守已授权范围，单次 API smoke、无重试、仅脱敏统计；记录 API 真实验收与合成网页验收的各自范围。
6. 未确认的账户全部权限、公开部署及缓存用途保留待核实；本次实施范围为已批准的本地查询。

## 尚待确认

2026-10-31 核查已确认官方 CLI 文档包含 `search-train` 参数和输出示例；真实 Key 单次查询也已成功，但未确认稳定独立服务端契约。本次 10 个结果条目的 `adultPrice` 均缺失，所检查的 `currency`、`priceUnit`、`priceBasis`、`remainingSeats` 字段亦未出现；不得将示例视为必返字段，也不能据此写入确定票价。示例 `adultPrice` 与具体席别、税费或人数基准的关系仍未定义。v0.2 已增加受控官方 HTTPS 详情链接、品牌及纯文本提示展示；不可信链接省略。本地 API 真实查询也已通过，以下供应商语义问题仍保留。

- 面向第三方服务端的官方 API 接口和结构化响应是否公开稳定，还是 Skill 只支持 CLI。
- 搜索结果中的价格是区间/起价/具体席别价，是否含税费，是否实时可购。
- 铁路查询权限是否需单独开通、调用额度与缓存期限。
- 本项目当前部署性质是否属于条款限制的商业用途或公开接口中转服务。
- 对外页面需要的署名/提示原文和摆放位置。
